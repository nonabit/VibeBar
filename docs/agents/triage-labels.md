# Triage Labels

技能使用五个 canonical triage roles。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已完整说明，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，使用上表右侧对应的标签字符串。
